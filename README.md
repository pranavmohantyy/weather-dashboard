# Weather Dashboard

A React-based weather dashboard that allows users to search for a city and view current weather, hourly forecasts, and a 7-day forecast.

## Features
- Search for any city to get weather data.
- Hourly and weekly forecasts with temperature graphs.
- Toggle between Celsius and Fahrenheit.
- Recent cities stored in local storage.
